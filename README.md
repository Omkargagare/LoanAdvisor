# 💰 Loan Adviser System

A basic full-stack project that helps users find suitable loan options based on their profile.

---

## 🚀 Tech Stack

* Backend: Spring Boot
* Frontend: React
* Database: MySQL

---

## 🧠 Features (Current)

* User Registration & Login (JWT Authentication)
* Input user details (region, income, occupation, purpose)
* Basic loan recommendation
* EMI calculation

---

## ⚙️ Setup Instructions

### Clone Repository

```bash
git clone https://github.com/your-username/loan-adviser.git
cd loan-adviser
```

### Backend

```bash
cd backend
mvn spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm start
```
